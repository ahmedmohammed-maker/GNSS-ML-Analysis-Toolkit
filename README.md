The GNSS ML Comparison App is an open-source MATLAB-based toolkit designed for comprehensive analysis and denoising of GNSS coordinate time series. It provides a unified platform that integrates five supervised machine learning regression algorithms — Gaussian Process Regression (GPR), Support Vector Regression (SVR), Random Forest (RF), Gradient Boosting (GB), and K-Nearest Neighbours (KNN) — within a single, geodetically rigorous framework. The toolkit is architecturally organised into three functionally distinct layers: a configuration-and-dispatch layer comprising an interactive graphical user interface (GNSS_ML_Comparison_App) and a headless batch script (gnss_batch_run), a central orchestration hub (gnss_file_io) responsible for file validation, folder scanning, and batch loop management, and an algorithm layer housing the five denoising modules, all of which share a common core utility library (gnss_ml_utils). This separation of concerns ensures that no processing logic resides in the entry points, maintaining clean modularity and extensibility.

At the heart of the toolkit is a standardised five-stage preprocessing pipeline shared by all five ML methods, guaranteeing that observed performance differences are attributable solely to algorithmic differences rather than inconsistencies in data preparation. The pipeline sequentially performs IQR-based outlier removal with linear interpolation of flagged epochs, deterministic model fitting and subtraction via Ordinary Least Squares supporting up to 22 configurable periodic signals spanning seasonal harmonics, GPS draconitic year terms, ocean tidal loading aliases, atmospheric loading signals, and inter-annual components, followed by z-score normalisation, sliding-window feature matrix construction, ML model training and prediction, and finally deterministic model restitution to recover physically meaningful coordinate units. The toolkit further incorporates formal step and offset detection, period auto-detection via the Lomb-Scargle periodogram with false-alarm probability gating, and time-series cross-validation, making the preprocessing pipeline both scientifically rigorous and adaptable to diverse GNSS data types including daily, high-rate, and weekly series.

The toolkit's outputs are designed to support both single-station interactive analysis and large-scale batch processing across entire GNSS networks. For each station and coordinate component, it automatically produces a denoised coordinate CSV, a per-station summary CSV, and a MATLAB .mat file, with results aggregated into a master batch_summary.csv across all stations and methods. Performance is evaluated through a comprehensive set of metrics including residual standard deviation, SNR improvement, noise reduction percentage, RMSE, MAE, AIC, BIC, Jarque-Bera residual normality test, and autocorrelation-corrected velocity uncertainty. Nine-panel diagnostic figures are generated automatically, presenting metric comparisons, time-domain decompositions, power spectral density plots, and velocity estimates simultaneously, providing users with a complete, publication-ready analytical portrait of each denoising result without any manual post-processing.
